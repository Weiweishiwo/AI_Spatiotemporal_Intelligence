# 需求文档

## 1. 应用概述

### 1.1 应用名称
AI智能体时空智能平台官网

### 1.2 应用描述
面向政企客户的B端科技网站，展示AI智能体时空智能平台的产品能力、解决方案与落地案例，采用明亮高级动态科技风格，主色调为白+浅灰+雾蓝，点缀科技青，提供官网首页展示、用户注册与登录功能。

## 2. 用户与使用场景

### 2.1 目标用户
- 厂区/园区管理决策者
- 政企客户采购负责人
- 技术方案评估人员
- 新用户（需注册）
- 已注册平台用户

### 2.2 核心使用场景
- 了解平台产品能力与解决方案
- 查看落地案例与合作客户
- 预约方案演示
- 注册平台账号
- 登录平台系统

## 3. 页面结构与功能说明

### 3.1 页面结构

```
├── 官网首页
│   ├── 顶部导航栏
│   ├── 首屏Hero区
│   ├── 核心能力板块
│   ├── 园区巡检解决方案
│   ├── 落地案例
│   └── 合作客户
└── 登录/注册页面
    ├── 左侧品牌视觉区
    └── 右侧表单区（登录模式/注册模式）
```

## 4. 业务规则与逻辑

### 4.1 导航跳转规则
- 顶部导航菜单点击后跳转至对应页面或锚点
- 首页菜单项跳转至官网首页顶部
- 其他菜单项跳转至对应功能页面或首页对应模块锚点

### 4.2 锚点滚动规则
- 点击包含锚点的链接（如/#capabilities）或按钮（如「了解平台能力」）后，页面平滑滚动至目标区块
- 滚动时自动计算并补偿固定导航栏高度，确保目标区块顶部不被导航栏遮挡
- 滚动动画平滑自然

### 4.3 注册验证规则
- 用户名不得为空，长度3-20字符
- 邮箱格式必须合法
- 密码长度不少于6字符
- 确认密码必须与密码一致
- 用户名和邮箱不得与已注册用户重复
- 验证通过后创建用户账号，自动登录并跳转至官网首页
- 验证失败提示对应错误信息

### 4.4 登录验证规则
- 用户输入用户名/邮箱和密码后点击登录按钮
- 系统验证用户名/邮箱和密码正确性
- 验证通过后跳转至官网首页
- 验证失败提示错误信息

### 4.5 记住密码规则
- 用户勾选「记住密码」复选框后
- 下次访问登录页面时自动填充账号信息

### 4.6 模式切换规则
- 用户在登录模式下点击「立即注册」链接，表单切换至注册模式
- 用户在注册模式下点击「立即登录」链接，表单切换至登录模式
- 切换时清空表单输入内容

## 5. 视觉与动态规范

### 5.1 色彩规范
- 主色调：白+浅灰+雾蓝
- 点缀色：科技青
- 禁用深色背景
- 整体明亮高级科技风格

### 5.2 布局规范
- 大留白网格布局
- 现代无衬线字体
- 柔和渐变
- 细线几何装饰

### 5.3 动态效果规范
- 动态效果包含：
  - 轨迹流动
  - 模块平滑入场
  - 扫描波纹
  - 点位标记淡入
  - 锚点平滑滚动
- 动态柔和不浮夸
- 禁止粒子爆炸等花哨特效
- 禁止赛博、暗黑、霓虹效果

### 5.4 风格统一性
- 官网首页与登录/注册页面视觉风格统一
- 页面间视觉延续
- 动态克制高级
- 玻璃轻质感
- 适配电脑端

## 6. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 用户名/邮箱或密码为空 | 提示「请输入用户名/邮箱」或「请输入密码」 |
| 用户名/邮箱或密码错误 | 提示「用户名/邮箱或密码错误，请重新输入」 |
| 注册时用户名为空或不符合规则 | 提示「用户名长度需为3-20字符」 |
| 注册时邮箱格式不合法 | 提示「请输入合法的邮箱地址」 |
| 注册时密码长度不足 | 提示「密码长度不得少于6字符」 |
| 注册时两次密码不一致 | 提示「两次输入的密码不一致」 |
| 注册时用户名或邮箱已存在 | 提示「用户名或邮箱已被注册」 |
| 网络请求失败 | 提示「网络异常，请稍后重试」 |
| 未勾选记住密码 | 下次访问不自动填充账号信息 |
| 锚点目标区块不存在 | 不执行滚动操作 |

## 7. 验收标准

1. 用户访问官网首页，点击Hero区「了解平台能力」按钮，页面平滑滚动至「核心能力板块」区域且不被导航栏遮挡
2. 用户点击顶部导航栏中的锚点链接（如产品能力），页面平滑滚动至对应区块且不被导航栏遮挡
3. 用户点击顶部导航栏「登录」按钮，跳转至登录页面
4. 用户在登录页面点击「立即注册」链接，表单切换至注册模式
5. 用户在注册模式下输入用户名、邮箱、密码、确认密码，点击「注册」按钮完成注册
6. 注册成功后自动登录并跳转至官网首页
7. 用户在登录页面输入用户名/邮箱和密码，点击「登录」按钮，验证通过后跳转至官网首页
